4. Step 1 — Install Ollama & Pull the Model


This is a one-time setup on the developer machine. Ollama runs as a background service on localhost:11434 and serves the LLM locally.

4.1  Install Ollama
Go to ollama.com and download the Windows installer
Run the installer — Ollama installs as a background Windows service
Verify it is running by opening a browser and visiting: http://localhost:11434
You should see the text: Ollama is running

4.2  Pull the Recommended Model
Open a terminal (Command Prompt or PowerShell) and run:

ollama pull llama3.2

This downloads a ~2 GB model file once. After that, the model is available offline forever with no internet needed.

4.3  Model Recommendations for This Machine
Hardware: Intel i5-12500H, 16 GB RAM, Intel Iris Xe (integrated GPU). No dedicated GPU — all inference runs on CPU.

5. Step 2 — Backend Changes


5.1  Update chatbot.py (2-line change)
Find and replace only the LLM initialisation lines. Everything else in chatbot.py stays the same.

REMOVE these lines:
from langchain_google_genai import ChatGoogleGenerativeAI
llm = ChatGoogleGenerativeAI(model="gemini-1.5-flash", temperature=0.3)

ADD these lines instead:
from langchain_community.llms import Ollama
llm = Ollama(model="llama3.2", temperature=0.3)

Also remove any line that loads the .env file or reads GOOGLE_API_KEY — these are no longer needed.

5.2  Create main.py (FastAPI Application)
This is the main new backend file. It exposes 4 REST API endpoints that the React frontend calls.

Route
Request Body
Response

CORS Configuration (required for React dev server)
FastAPI must allow requests from the React dev server running on port 5173. Add this at the top of main.py:

from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_methods=['*'],
    allow_headers=['*'],
)

5.4  How to Run the Backend
Open a terminal in the backend/ folder
Create and activate a virtual environment:
python -m venv venv
venv\Scripts\activate
Install dependencies:
pip install -r requirements.txt
Make sure Ollama is running (see Step 1)
Start the FastAPI server:
uvicorn main:app --reload --port 8000
The API is now live at: http://localhost:8000
Visit http://localhost:8000/docs to see the auto-generated API documentation

6.2  Configure Vite Proxy (vite.config.js)
Add a proxy so that React API calls to /api/* are forwarded to FastAPI on port 8000. This avoids CORS issues in development.

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:8000',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  }
})
